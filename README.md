# RBS Make-Over

Single-page studio site for **Rachna Bhardwaj** (`@rbsmakeoverstudio`) — unisex bridal, party, hair and men's grooming in Delhi NCR.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

Next.js (App Router) · TypeScript · Tailwind v4 · `next/image` (AVIF/WebP, 480 / 800 / 1280 / 1920) · `next-themes`

## Content

All copy, alt text, prices and image wiring live in [`src/content/content.ts`](src/content/content.ts). Stock frames are tagged `isStock: true` with a `// REPLACE WITH CLIENT PHOTO` comment.

## Photo: Unsplash
